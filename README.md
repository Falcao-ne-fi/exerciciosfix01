# exerciciosFix01

#🧪 1. Estrutura básica
#👉 Crie uma página HTML com:
    • Estrutura completa (<!DOCTYPE>, <html>, <head>, <body>)
    • Um título na aba do navegador
    • Um texto simples no corpo

#🧪 2. Títulos e parágrafos
#👉 Crie uma página com:
    • Um <h1> (título principal)
    • Dois <h2> (subtítulos)
    • Três parágrafos explicando um tema livre

#🧪 3. Lista de compras
#👉 Crie:
    • Uma lista não ordenada (<ul>)
    • Com pelo menos 5 itens (<li>)
💡 Ex: alimentos, materiais escolares

#🧪 4. Lista ordenada
#👉 Crie:
    • Uma lista ordenada (<ol>)
    • Com 5 passos de uma atividade (ex: fazer café, estudar, etc.)

#🧪 5. Inserindo imagem
#👉 Crie uma página com:
    • Um título
    • Uma imagem usando <img>
    • Um parágrafo descrevendo a imagem
💡 Use imagem da internet (URL)

## 🧪 6. Página sobre um filme

### Objetivo
Criar uma página HTML contendo:

- Um título principal com `<h1>`
- O nome de um filme favorito
- Um parágrafo contando do que o filme fala
- Uma imagem do filme usando `<img>`

---

## 🧪 7. Meus hobbies

### Objetivo
Criar uma página contendo:

- Um título principal
- Uma lista não ordenada com `<ul>`
- Pelo menos 5 hobbies usando `<li>`
- Um parágrafo explicando qual hobby você mais gosta

### Sugestões
- Jogar videogame
- Ler livros
- Andar de bicicleta
- Ouvir música

---

## 🧪 8. Receita simples

### Objetivo
Criar uma página HTML com:

- Um título da receita usando `<h1>`
- Uma lista de ingredientes com `<ul>`
- Uma lista ordenada com `<ol>` mostrando o passo a passo
- Um parágrafo final dizendo se gosta da receita

### Sugestões
- Bolo
- Sanduíche
- Brigadeiro
- Vitamina de frutas

---

## 🧪 9. Página de apresentação

### Objetivo
Criar uma página contendo:

- Seu nome em um `<h1>`
- Sua idade em um parágrafo
- Sua cidade em outro parágrafo
- Uma frase sobre algo que você gosta de fazer

## 🧪 10. Links favoritos

### Objetivo
Criar uma página HTML contendo:

- Um título principal

- Cada link deve abrir um site diferente

### Sugestões
